# Bank of Welfare (BOW)

Public welfare initiative website for https://bowinitiative.org.

## Development

Use Node.js 22 or later. Run `npm install`, then `npm run dev`.
Run `npx tsc --noEmit` and `npm run build` before publishing.

## Cloudflare Pages

- Repository: Manus-Dei-Global/BOW--Bank--Of--Welfare
- Production branch: main
- Build command: npm run build
- Output directory: dist
- Root directory: repository root

The current public site is static and does not require environment variables or AppDeploy services. The legacy backend directory is retained for history and is not deployed by Pages.

Support applications and partnership enquiries prepare a WhatsApp message to +2348086001110. Visitors must press Send in WhatsApp to deliver the message; the website does not store applications.

The public frontend was updated from the source archive supplied on 2 November 2026. The archive's build manifest describes its original build and is not a deployment configuration.
